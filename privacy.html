개인정보처리방침

채널 운영 (Channel Ops) · 시행일 2026-11-09

채널 운영은 채널 소유자 본인이 자신의 YouTube 채널을 관리하려고 쓰는 개인용 도구입니다. 다른 사람의 계정으로 로그인하거나 다른 사람의 데이터를 수집하지 않습니다.

1. 사용하는 Google 사용자 데이터

  • YouTube Data API: 운영자 채널의 기본 정보, 업로드 영상 목록, 재생목록, 영상 업로드·예약, 댓글 읽기·답글·검토 상태 변경
  • YouTube Analytics API: 운영자 채널의 조회수 등 성과 지표(읽기 전용)

2. 사용 목적

운영자가 승인한 영상의 업로드·예약, 재생목록 정리, 댓글 관리, 성과 요약에만 씁니다. 광고, 프로필 작성, 판매 목적으로 쓰지 않습니다.

3. 저장

로그인 토큰과 처리 기록은 운영자 본인의 컴퓨터(맥북·맥미니)에만 저장되고, 접근 권한이 제한된 폴더에 보관됩니다. 별도 서버나 데이터베이스로 보내지 않습니다.

4. 제3자 제공

Google 사용자 데이터를 판매하거나 제3자에게 넘기지 않습니다. 단, 댓글 분류와 답글 초안 작성을 위해 공개 댓글의 텍스트를 AI 서비스(Anthropic의 Claude API)로 보낼 수 있으며, 이 데이터는 그 처리에만 쓰입니다.

5. 보관 기간과 삭제

처리 기록은 운영에 필요한 동안만 보관하고, 운영자가 언제든 삭제할 수 있습니다. 접근 권한은 Google 계정 보안 설정에서 언제든 철회할 수 있습니다.

6. 함께 적용되는 정책

이 도구는 YouTube API 서비스를 사용하며 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다. 이 도구의 Google API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.
